# TCG Speed Shipper

A super fast tool that converts TCGplayer CSV order exports into ready-to-print shipping labels in seconds.

## How it works
1. Upload your TCGplayer CSV file  
2. Instantly generate printable labels  
3. Print and ship

## Features
- No login required  
- Works with large CSV files  
- Generates labels in seconds  
- Simple, clean, fast
