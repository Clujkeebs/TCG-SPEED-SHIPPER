# How to try the extension (Sam)

**You need desktop Chrome or Edge on a Mac, Windows or Linux computer. Your iPad cannot run extensions.** Everything in it is practice mode: a made-up shop. Nothing real is touched.

1. On the computer, get the file `tcg-speed-suite-…zip` (ask Claude to run `npm run build` in `suite/extension`, or use the folder `suite/extension`). If it is a zip, unzip it.
2. In Chrome, open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose the unzipped folder.
4. Click the puzzle icon, pin **TCG Speed Suite**, then click it and open **Settings**. Switch on **Agent side panel**.
5. Open the side panel (Chrome menu, then **Side panel**, then **TCG Speed Agent**). A short tour starts.

**What to click:** type "Reprice my cards 5% under market" and press Enter. It shows a plan, then a card. Read it, press **Approve** (or **Deny**), and try **Undo**. Press **Stop** any time. Add a "demo job" and watch the number on the toolbar icon.

**What practice mode means:** the shop is invented, nothing leaves your computer, and it never changes anything until you press Approve. **Clear everything** in Settings erases it all.
