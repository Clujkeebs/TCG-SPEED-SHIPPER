TCGplayer Return Policy for Sellers: Wrong Cards, Swaps & Damage

A practical seller guide to buyer’s remorse, a wrong card or swapped order, damage in transit, and the refund options TCGplayer lists.

Updated September 28, 2026 · 10 min read

Short answer: TCGplayer sellers do not have to accept a buyer’s-remorse return, but a wrong card, swapped order, or shipping-damage claim follows a specific resolution path. For a wrong single, offer a partial refund, a confirmed replacement, or a full refund after a prepaid return. If you request a return for a seller-side mistake, you pay return shipping. Start with TCGplayer’s Seller Guide to Refunds and Returns for the exact case.

If a TCGplayer seller sent the wrong card or item

TCGplayer treats an incorrect single—such as the wrong set, printing, or card—as an inventory issue. The seller should work with the buyer to agree on one of the guide’s three options. For these singles claims, the buyer should contact you as soon as possible (within 48 hours of arrival is recommended) and no later than 30 calendar days after the Estimated Delivery Date (EDD). The official wrong-card instructions give the details.

  1. Partial refund: If the buyer wants to keep the incorrect card, offer a partial refund based on the difference between the ordered and received card prices. If the wrong card costs more, you may not charge the buyer extra to keep it.
  2. Replacement: If you have the correct card, offer to send it. The buyer must confirm before you ship the replacement. If you want the incorrect card returned, provide a prepaid return label or package and pay the return cost.
  3. Return for a full refund: If you request the wrong card back, provide a prepaid return method and cover its shipping cost before refunding.

The buyer must agree to the resolution before you proceed. If you and the buyer cannot agree, escalate the message thread to TCGplayer. Do not require photos of an incorrect card as a condition for resolving the issue.

How to fix a TCGplayer swapped order

TCGplayer describes swapped orders as cases where the wrong shipping label was applied to one or more packages. If you find a package you thought you had already shipped, check your records or the Seller Portal orders page to identify the customer who received it. Message that customer through the order’s message center, explain the mix-up, and ask them to return the package. You are responsible for providing a prepaid return package or label. Then contact the original customer and offer to reship their order if you have inventory, or give them a full refund. TCGplayer recommends escalating the recipient’s message thread if they do not respond or return the package within 48 hours.

If a customer tells you they received someone else’s order, ask for the order number from the packing slip. If the slip is unavailable, ask what was inside. Use that information to find the other impacted orders, contact each affected customer, and request the incorrect packages back with prepaid return shipping. You can offer to reship each customer’s order without waiting for the incorrect package to return, or offer a full refund. Escalate to TCGplayer when you need help, especially if a customer does not respond or return the package. See the swapped-order instructions.

Label-and-slip mix-ups can put the wrong order details with a package. TCG Speed Shipper generates each label and packing slip from the same order row in your TCGplayer CSV. Its “Label + slip” format prints one order per sheet, with that order’s label above its packing slip. Keeping the pair on one page can help you keep them matched; it does not prevent every swap or handle refunds and returns.

TCGplayer damaged package: unopened, opened, or only the packaging?

For an unopened package damaged in transit, TCGplayer says the buyer is eligible for a refund after returning it. You provide the prepaid return label or package and pay that return cost. After the package comes back, use the damaged-package refund steps below. The damaged-shipping section also links to these carrier claim pages:

  • USPS claims
  • UPS claims
  • FedEx claims

If the buyer opened the package and only some products are damaged, handle the affected products as condition issues; TCGplayer says most transit-damaged items are treated as “Damaged” condition for a partial refund. If every product is damaged, the buyer is eligible for a refund after returning the package, and you provide the prepaid return method. If the package is damaged but its contents are fine, ask what kind of damage occurred and use the feedback to review your packaging.

Sealed products have an additional limit: the buyer may return a sealed product damaged in transit only if they have not opened the sealed product itself. If they open the product or its included materials, it is no longer eligible for a return or refund. A buyer who returns an otherwise eligible sealed product in the same condition it was sent pays tracked return shipping; when the return is due to your mistake, you provide a prepaid, trackable return method.

Buyer’s remorse and unauthorized “Return to Sender” packages

You are not required to accept a return or issue a refund for buyer’s remorse, such as a change of mind or finding a better price, unless the order has another issue like a wrong set or condition. If you choose to authorize a buyer’s-remorse return, the buyer pays return postage. You can direct the buyer to TCGplayer’s Buyer’s Remorse policy; if they push back, the guide says you may escalate the message thread.

A package returned as “Return to Sender” or “Refused” without prior communication from the buyer is not eligible for a refund. If the buyer contacts you after it comes back, point them to the Buyer’s Remorse section and escalate the thread. TCGplayer lists exceptions for packages marked undeliverable by the post office, returned because postage was due, or sent to someone else because of an address error that was not the buyer’s fault. For an undeliverable package, contact the buyer and offer a refund or reshipment; if they choose a reshipment, provide an updated Estimated Delivery Date (10 business days is recommended for domestic orders). If a postage-due package comes back, offer a refund or reshipment after it returns; if the buyer already paid the postage due, provide a partial refund for that postage amount. For a seller-side addressing error, contact the correct buyer and offer a refund or reshipment if they are willing to wait. If they choose a reshipment, provide an updated Estimated Delivery Date (10 business days is recommended for domestic orders). See TCGplayer’s unauthorized-return exceptions for the full steps.

How to issue the right TCGplayer refund

Use the refund type and reason that match the resolution. TCGplayer’s refund instructions use these exact labels:

Open the order page and choose Partial Refund or Full Refund. Select Buyer Initiated for Refund Origin and the case-specific Refund Reason above. Enter a short explanation in the Cancellation Reason box. For a partial refund, select the affected item or items and enter the correct quantity; then select Refund Order. For a full refund, select Refund Order after entering the reason.

When TCGplayer may step in

TCGplayer reserves the right to resolve a customer issue directly if a seller does not respond within 2 business days, fails to ship within 48 hours of receiving an order, violates Community Guidelines in a response, asks the buyer to accept a resolution outside the policy, makes the buyer pay return shipping on a seller-requested return, or uses delaying tactics such as demanding photos before resolving the issue or asking the buyer to wait an extended period. Customer Service may also step in when the buyer and seller cannot reach a resolution, tracking is invalid or absent, tracking shows delivered, a seller ships a replacement before the buyer confirms, or the seller does not follow through on an agreed resolution. These escalation conditions are in TCGplayer’s refund and return guide.

FAQ

What should a TCGplayer seller do after sending the wrong card?

Offer a partial refund if the buyer wants to keep it, a replacement if you have the correct card and the buyer confirms, or a full refund after requesting the wrong card back. If you want it returned, provide prepaid return shipping and cover the cost.

Do TCGplayer sellers have to accept a buyer’s-remorse return?

No. TCGplayer says sellers do not have to accept a return or refund for buyer’s remorse. If you authorize a return for that reason, the buyer pays return postage.

What if a TCGplayer package is returned to sender without notice?

A “Return to Sender” or “Refused” package with no prior communication is not eligible for a refund, except for the guide’s undeliverable, postage-due, and seller-side address-error cases. Handle those exceptions according to the official return guidance.

What should I do about a TCGplayer package damaged in shipping?

If it is unopened or all products are damaged, arrange a prepaid return and refund after it comes back. Treat only some damaged products as condition issues. If the packaging is damaged but the products are fine, ask for details as packaging feedback.

What order number should I ask for when customers receive swapped TCGplayer orders?

Ask for the order number on the packing slip, or the contents if there is no slip. Use it to find the other affected orders, contact those customers, arrange prepaid returns, and offer a replacement or full refund.

Which refund reason applies to a wrong card or damaged package?

For a wrong card, use Product - Inventory Issue. For a returned order damaged in shipping, use Package - Damaged. In both flows, the source lists Buyer Initiated as the Refund Origin.
