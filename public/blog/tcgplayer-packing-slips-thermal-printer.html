How to Print TCGplayer Packing Slips on a Thermal Printer (Label, Slip, Label, Slip)

One roll, one pass: each order's address label, then its packing slip, then the next order. Here's how to set it up and fix the usual problems.

Published October 6, 2026 · 5 min read

If you ship TCGplayer orders with a 4x6 thermal printer (Rollo, MUNBYN, Dymo 4XL and the like), packing slips are the annoying part. The Seller Portal makes them for letter-size paper, so you either print them on a second printer and match them up by hand, or send them to the thermal printer and get tiny text spread across several labels. There's a cleaner way: print every order as label, slip, label, slip, so you peel two labels off the roll and the order is done.

What you need

  • Your shipping CSV: Seller Portal → Orders → tick the orders → Export Shipping.
  • The packing slips for the same orders: with the same orders ticked, click Packing Slip. That gives you a PDF, not a CSV.
  • A 4x6 thermal printer and labels.

Step by step

1

Open TCG Speed Shipper and drop in the Export Shipping CSV. Your orders show up as a list, with any order that needs tracking flagged.

2

Click + Add TCGplayer packing slips (PDF) and add the Packing Slip PDF. Each slip is matched to its order by order number, and you're told if one is missing.

3

Pick the 4x6 format and leave packing slips turned on.

4

Download and print at 100% scale. Each order comes out as its address label, then its slip on its own 4x6 label, sized to fit. If TCGplayer gave you a 4x6 slip already, it prints exactly as is.

It all runs in your browser. The CSV and the PDF are never uploaded anywhere.

Fixes for the usual problems

The return address prints too light

Thermal printers turn gray text into faint dots, so a gray return address can come out nearly invisible. Print it in solid black, and if it's still light, tick Print the return address in bold under Return address. The setting is saved for next time.

A line cuts through my meter postage

If you stamp postage with a meter, the divider under the return address can run through the postage area. Tick No divider line under the return address and the top right stays clear.

The slip text is too small

A letter-size slip squeezed onto 4x6 gets smaller. Long card lists shrink the most. If an order has a very long list, consider the 8.5x11 Label + packing slip format for that batch instead: one sheet per order, label on top, slip below, cut on the dashed line.

Labels and slips get out of order

They can't if they print together, because each slip prints right behind its own label. If you print labels and slips separately, use Slips in label order, which re-sorts TCGplayer's slips to match your label stack.

Do I even need a packing slip?

It depends on the order. We wrote up what TCGplayer actually says, including the separate Direct rule, in Does TCGplayer Require a Packing Slip?
